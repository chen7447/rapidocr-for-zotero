# v1.10.0 设计稿 2：双栏阅读顺序（列检测 + 列内排序）

> 状态：待评审。批准后实施，单 commit，可独立 revert。
> 目标：双栏论文的文本层按「左栏全部 → 右栏全部」排序，复制/搜索不再左右交错。

## 问题

`postprocess.ts` 的 `readingOrder()` 按行聚类（y 重叠 ≥50% 归同线，线内按 x 排序）。双栏页面上左右栏同一基线的行会拼成一条"线"，复制顺序变成 `L1 R1 L2 R2 …`。

## 算法（保守策略：不确定就回退单列，永不劣化）

新增 `orderBoxes(boxes, pageWidth?)` 包裹现有 `readingOrder()`：

```
输入：det 框（raw 坐标，像素）、页宽
0. 框数 < 8 或未提供 pageWidth → 直接 readingOrder()（现行为）
1. 分离通栏框：宽 ≥ 55% 页宽的框（标题/摘要/跨栏图）
2. 其余框做 x 向覆盖直方图（100 桶）
3. 找空白沟（连续 0 覆盖段）：
   - 沟宽 ≥ 3.5% 页宽（144dpi 下 ≈ 38px ≈ 13pt，真实栏间距 5-10mm 一定满足）
   - 沟两侧各 ≥ 3 个框且各 ≥ 15% 的非通栏框数（显著性，防碎裂）
   - 沟数量 1~2（最多 3 列，超出视为病态 → 回退）
4. 按沟切分成列；框按中心 x 归入列
5. 每列内部用现有 readingOrder()（列宽内按行聚类是正确的）
6. 通栏框位置：
   - 全部位于列区顶部之上（典型标题/摘要）→ 最先输出，其后按列
   - 否则（页中部跨栏图等）→ 回退单列 readingOrder()（不冒险）
```

## 接入点

| 调用方 | 现状 | 改动 |
|--------|------|------|
| `ocr-worker.ts` detOnly → `nmsBoxes(boxes)` | 排序在 worker 完成 | `nmsBoxes(boxes, w)`（w 已在作用域） |
| `pdf-builder.ts` 写层前 `readingOrder(pageResult.boxes)` | 安全网重排 | 换 `orderBoxes(boxes, pageResult.pageWidth)`，确定性纯函数，与 worker 结果一致 |
| `nmsBoxes` 签名 | `nmsBoxes(boxes, contain?, iou?)` | 追加第 4 可选参 `pageWidth?`，不传 = 不做列检测（现有测试零改动） |

`readingOrder()` 本体不动、保持导出（单列语义不变）。

## 参数表（像素空间，144dpi）

| 参数 | 值 | 依据 |
|------|----|------|
| 通栏阈值 | 0.55 × 页宽 | 栏宽 ≤ ~45%，正文行不可能误判；标题/摘要/跨栏图 ≥ 70% |
| 沟宽下限 | 0.035 × 页宽 | 真实栏间距 5-10mm ≈ 1.3-2.6% 页宽，取近两倍防误判 |
| 沟侧显著性 | ≥3 框 且 ≥15% | 单侧只有 1-2 个框（如页码）不构成列 |
| 列数上限 | 3 | 三栏以上学术版面罕见，防病态切分 |

## 测试矩阵（全部纯函数单测，`tests/unit/postprocess.test.ts` 追加）

1. 标准双栏（左右各 20 框，y 区间交错）→ 输出 = 左列按 y 全部 → 右列按 y 全部
2. 单栏 → 顺序与现 readingOrder 完全一致（回归）
3. 通栏标题在上 + 双栏正文 → 标题最先，其后双栏
4. 页中部跨栏图 → 回退单列现行为（明确断言回退路径）
5. 三栏 → 三段顺序
6. 不传 pageWidth 的 nmsBoxes → 与现行为逐位一致（兼容性）

## 风险与边界

- **永不劣化原则**：任何检测不满足显著性/位置条件都回退现行为——最坏情况 = 现状。
- 复制顺序变化对搜索/全文索引无影响（索引是全文，不分顺序）。
- det 框是整行文本，不会半栏跨越沟（栏内行宽 < 栏宽）。
